# VETORA Animal Health — React + Vite Homepage

A responsive homepage implementation based on the approved VETORA design direction.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included interactions

- Responsive mobile navigation
- Product and animal mega menus on desktop
- Product wishlist toggle
- Add-to-cart with live cart count and toast feedback
- Newsletter form feedback
- Responsive layouts for desktop, tablet and mobile

## Images and content

Photos are loaded from Unsplash image URLs and require an internet connection.
Product packaging imagery is illustrative stock photography, not actual VETORA pharmaceutical product packaging.
Product names, prices, ratings, testimonials, contact details and shipping threshold are sample demo content. Replace them with approved business data before launch.
